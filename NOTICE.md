# Notice

This repository is a paper-focused derivative of
[SpatiotemporalGPs.jl](https://github.com/dev10110/SpatiotemporalGPs.jl), based
on commit `5c49a82f0877e0afcc3db0f760d2f0123b9d0adf`. The original MIT license and
copyright notice are preserved in `LICENSE`.

The cleanup was prepared for the paper “Kalman-Bucy Filtering with Randomized
Sensing: Fundamental Limits and Sensor Network Design for Field Estimation” by
Xinyi Wang, Devansh R. Agrawal, and Dimitra Panagou.

Files under `results/` are generated by the experiment scripts in this cleaned
repository. Each run records its profile, configuration, seed, Julia version,
commands, and repository revision when available.
